1. Proveedor de Identidad y Credenciales

Selecciona tu Identity Provider e ingresa las credenciales generadas en su consola de administración.

2. Endpoints de Integración (Spriteboard SP)

Parámetros que debes registrar en la consola de tu proveedor de identidad (Google Cloud, Entra o SAML IdP).

ACS URL / Callback URL (Consumer URL)
/api/auth/sso/saml/callback
SP Entity ID (Audience URI / Identifier)
/api/auth/sso/saml/metadata
SP Metadata XML URL (Opcional)
/api/auth/sso/saml/metadata
Para Google Workspace o Entra ID OIDC, la URL de redirección autorizada es: /api/auth/sso/google/callback

3. Reglas de Autenticación y Dominios

Controla si el inicio de sesión vía SSO es obligatorio para proteger las cuentas de tu organización.

Asegúrate de tener registrados tus dominios en la sección de Dominios Corporativos para que el enrutamiento automático de login funcione.

4. Instrucciones de Despliegue Seguro

Sigue esta secuencia para evitar bloquear el acceso de tu personal corporativo:

1
Crear aplicación en IdP Registra una nueva app SAML 2.0 u OpenID Connect en tu consola corporativa.
2
Asignar credenciales y guardar Ingresa el Client ID/Secret o Entrypoint en este panel y guarda los cambios.
3
Verificar inicio de sesión Realiza una prueba de acceso corporativo en una ventana privada antes de forzar SSO obligatorio.
Guardar y Aplicar Cambios Los parámetros actualizados se sincronizan de inmediato con el cluster de autenticación.
